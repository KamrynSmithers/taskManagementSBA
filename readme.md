Reflection: During this project, the biggest challenge I faced was figuring out the correct functions, and function “wording” for the filter buttons.  Upon reading the requirements, the filter tasks section asks for the page to only show the tasks that match the selected category or status. This required me to be more careful in writing descriptive function names and making sure the logic is filtering based on the users selections. I decided to go with the filter buttons instead of another drop down, although there is limited styling I wanted to showcase variety within the basic webpage. If given more time, there would be improved styling on the web page. Though all of the functions needed are supplied, there is little UX enjoyment.
